# The Lost Expedition

Modded Minecraft 1.21.1 (Fabric) for TLauncher or the official Minecraft Launcher.

## Install or update

1. Close Minecraft.
2. Download [Install.bat](https://raw.githubusercontent.com/oguzhan00yildiz/lost-expedition/main/Install.bat)
   (right-click, "Save link as") and double-click it.
   If Windows shows "Windows protected your PC", click "More info", then "Run anyway".
3. Open your launcher:
   - TLauncher: pick **Lost Expedition 1.21.1** in the version list. Set memory to 6 to 8 GB.
   - Minecraft Launcher: pick the installation **The Lost Expedition** next to the Play button.
     It already uses 6 GB of memory.
4. Press Play. In Multiplayer, join the server address you got from the server owner.

Run `Install.bat` again whenever the pack gets an update.
Run it again also after you change your Minecraft name or switch accounts.

## Keys

| Key | Action |
|---|---|
| V | Voice chat menu |
| B | Backpack |
| J | Emote wheel |
| U | Waypoints |
| K | Shaders on or off |
| O | Pick a shader pack |

## What the installer changes

- Adds the version `.minecraft\versions\Lost Expedition 1.21.1`.
- Puts the mods in `.minecraft\lost-expedition\mods`. Your normal `mods` folder stays untouched.
- Adds 2 shader packs to `.minecraft\shaderpacks`.
- Fixes key clashes between mods in `options.txt`.
- Turns on connected glass (Continuity resource packs) in `options.txt`. Your other resource packs stay on.
